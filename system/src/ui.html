准备就绪未选中节点

一键变体

先选择“基础状态”和“附加 Style”，再点击生成按钮。选中 Frame 时会先自动 Create component；选中独立 Component 时会新建变体集；选中已有变体集时，只会在现有 State / Checked 基础上追加 Style。

基础状态

仅 Style 不生成 State / Checked；跳转按钮生成 State；选择按钮生成 State + Checked。

  • 跳转按钮：State=Normal / Hover / Pressed
  • 跳转按钮带禁用态：State=Normal / Hover / Pressed / Disabled
  • 选择按钮：Unchecked 和 Checked 各 3 个 State
  • 选择按钮带禁用态：Unchecked 和 Checked 各 4 个 State

附加 Style

  • 常态和完成：Style=Normal / Style=Complete
  • 排名：Style=1st / Style=2nd / Style=3rd
  • 不添加 Style：保持原 3 / 4 / 6 / 8 变体行为

组合示例

  • 仅 Style + 常态和完成：2 个变体
  • 跳转按钮 + 常态和完成：6 个变体
  • 选择按钮 + 排名：18 个变体

按节点名切换状态层（可选）

仅在选中 Frame 或独立 Component 新建变体时生效。插件会递归检查全部后代，忽略大小写和首尾空格，只精确匹配 Hover、Pressed、Disabled；例如 Icon_Hover 不会匹配。同名节点会全部处理，节点不存在时会跳过且不报错。

  • State=Normal：关闭 Hover、Pressed、Disabled。
  • State=Hover：只打开 Hover。
  • State=Pressed：打开 Hover，同时打开 Pressed（如有）。
  • State=Disabled：只打开 Disabled（如有）。

选择按钮的 Checked 与 Unchecked 使用同一套 State 规则：

  • State=Pressed, Checked=Checked / Unchecked：打开 Hover 和 Pressed（如有）。
  • State=Hover, Checked=Checked / Unchecked：只打开 Hover。
  • State=Normal, Checked=Checked / Unchecked：关闭全部状态层。
  • 8 状态模式的 State=Disabled：只打开 Disabled（如有）。

仅 Style 模式和已有 Component Set 追加 Style 不使用该选项；关闭选项时完全保留原有可见性。

生成标准按钮结构（可选）

仅在选中 Frame 或独立 Component 新建 State 变体时生效。每个生成的变体会整理为根层 Content + HotZone：原内容按原顺序放入 Content，HotZone 位于根层最上方并覆盖组件全尺寸。

  • 根层已有名称精确匹配 Content / HotZone 的 Frame 时会复用并补齐；名称忽略大小写和首尾空格。
  • 缺少 Content 或 HotZone 时自动创建；HotZone 内已有内容会移入 Content。
  • HotZone 自动设为透明、无描边、横纵 Stretch，并添加程序控制和按钮属性。
  • 同名但不是 Frame 的节点不会被当作标准容器；它会作为普通内容放进 Content。

仅 Style 模式和已有 Component Set 追加 Style 不使用该选项。关闭后不会改动原有节点结构。
