# NGR Figma UI 锻造台傻瓜式使用教程

这份教程只讲怎么用，不讲代码。第一次接触 Figma 插件也可以照着完成。

## 先记住一句话

**先在 Figma 里选中节点，再回插件点功能按钮。**

如果插件显示的选中数量不对，点击右上角的“刷新”。

## 1. 安装插件

1. 下载最新正式版 ZIP。
2. 把 ZIP 完整解压到一个固定文件夹。
3. 打开 Figma Desktop。
4. 进入 `Plugins → Development → Import plugin from manifest`。
5. 选择解压目录里的 `manifest.json`。
6. 从 Development 插件列表打开“NGR Figma UI 锻造台”。

看到插件窗口，并且底部显示“准备就绪”，就说明安装成功。

## 2. 给节点改成规范名称

1. 在 Figma 画布里选中要改名的节点。
2. 打开插件的“命名”页。
3. 在推荐词条里找到合适的名称。
4. 点击词条。

节点名称已经改变，就说明操作成功。

如果想把中文名称翻译成英文，在“翻译命名”中输入中文，再点击翻译按钮。翻译接口需要先到设置页填写百度翻译配置。

## 3. 批量添加程序控制

1. 在 Figma 里按住 `Shift`，选择多个节点。
2. 打开插件的“功能”页。
3. 确认插件底部显示的选中数量正确。
4. 点击“批量添加程序控制”。

看到“新增、已存在、失败”的数量提示，就说明处理完成。这个功能只处理你明确选中的节点，不会偷偷处理子节点。

## 4. 一键整理画板

1. 先复制一份画板作为备份。
2. 在插件“功能”页打开整理规则。
3. 决定是否删除隐藏节点、删除 Mask、解散 Group。
4. 选中一个主画板。
5. 点击“一键整理并命名画板”。

第一次使用建议在测试画板上操作。隐藏节点和 Mask 一旦按规则删除，需要依靠 Figma 撤销恢复。

## 5. 一键生成按钮变体

1. 选中一个 Frame 或独立 Component。
2. 打开插件“变体”页。
3. 选择按钮类型：
   - 跳转按钮：3 状态或 4 状态。
   - 选择按钮：6 状态或 8 状态。
4. 不需要 Style 时选择“不添加 Style”；需要两套外观时先准备好对应命名节点，再选择“常态和完成”或“排名”。
5. 需要自动控制状态层时，勾选“按节点名切换状态层”。
6. 需要标准按钮结构时，勾选“生成标准按钮结构”。
7. 点击蓝色生成按钮。

状态层名称必须精确写成：

- `Normal`
- `Hover`
- `Pressed`
- `Disabled`
- `Checked`

选择按钮的标准规则是：State 控制 `Normal / Hover / Pressed`，Checked 属性单独控制 `Checked`。`Pressed` 状态继续同时打开 `Hover`。

| 变体 | Normal | Hover | Pressed | Checked |
|---|---:|---:|---:|---:|
| State=Pressed, Checked=Checked | 打开 | 打开 | 打开 | 打开 |
| State=Pressed, Checked=Unchecked | 打开 | 打开 | 打开 | 关闭 |
| State=Hover, Checked=Checked | 打开 | 打开 | 关闭 | 打开 |
| State=Hover, Checked=Unchecked | 打开 | 打开 | 关闭 | 关闭 |
| State=Normal, Checked=Unchecked | 打开 | 关闭 | 关闭 | 关闭 |
| State=Normal, Checked=Checked | 打开 | 关闭 | 关闭 | 打开 |

`Normal` 是所有变体共用的基础层，因此在任何 State、Checked 或 Unchecked 组合下都保持打开。`Icon_Hover`、`Icon_Checked` 这类名称不会被当作状态层。

“生成标准按钮结构”会把视觉内容放进 `Content`，并在最上层创建全尺寸透明的 `HotZone`。`HotZone` 会自动挂上程序控制和按钮属性。

> 当前程序已经按上表自动控制 Normal、Hover、Pressed、Disabled、Checked；节点不存在时直接跳过，不会报错。

### 一次生成不同的风格样式

把第二套外观放进名为 `Complete` 的节点，选择“常态和完成”后生成。`Style=Complete` 自动打开 `Complete`，`Style=Normal` 自动关闭 `Complete`。比如 `State=Normal, Style=Complete` 显示完成风格，`State=Pressed, Style=Normal` 关闭完成风格并显示按下状态。

如果两套完整外观分别放在同级 `Normal` / `Complete` 容器中，并且 `Normal` 容器内还有 Normal、Hover、Pressed 等状态子层，插件会先按 Style 选一套外观，再按 State 切换内部状态。普通扁平 `Normal` 底层仍保持显示。

“仅 Style”只生成两种风格，不生成 State / Checked；已有变体集也可以直接追加 Style，保留原来的状态层。Style 显隐自动执行，不需要勾选“按节点名切换状态层”。排名风格同理，提前准备 `1st`、`2nd`、`3rd` 节点即可。

名称要完整匹配：`Icon_Complete` 不会被当作 `Complete`；大小写和首尾空格不影响匹配。缺少的风格节点会跳过，插件不会替你设计新的外观。

## 6. 插入模板

1. 打开“模板”页。
2. 先在模板设置里选择 Library 模板或内置模板。
3. Library 模板需要填写已经发布并且当前账号有权限访问的 Component Key。
4. 点击 PC 或 IOS 模板按钮。
5. 插入后检查名称、层级和实例内容。

## 7. 换电脑继续使用

1. 在旧电脑导出词库和配置。
2. 在新电脑重新导入正式版插件。
3. 导入词库和配置文件。
4. 百度翻译、OpenAI 或 Kimi 的密钥需要重新填写。
5. 先在临时 Figma 文件里测试一次，再处理正式项目。

## 出问题时先检查这 5 项

1. 是否使用 Figma Desktop，而不是浏览器版。
2. ZIP 是否已经完整解压。
3. Figma 选区是否正确。
4. 插件底部显示的选中数量是否正确。
5. 节点名称是否与功能要求完全一致。

仍然无法解决时，记录软件版本、操作步骤、选中节点类型和错误提示，再到 [GitHub Issues](https://github.com/907609732/NGR-Figma-UI-Forge/issues) 反馈。
