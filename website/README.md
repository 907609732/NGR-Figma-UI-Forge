# NGR Figma UI 锻造台官网

这是 Figma 插件 NGR Figma UI 锻造台的官网项目，内容覆盖产品定位、核心能力、交付工作流、内部安装方式、完整教程和常见问题。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm run lint
npm run build
npm test
```

## 内容结构

- `app/page.tsx`：官网首页内容
- `app/tutorial/page.tsx`：独立产品教程
- `app/tutorial/layout.tsx`：教程页元数据
- `app/globals.css`：官网视觉样式
- `public/product-hero.png`：首屏产品视觉图
- `public/og.png`：社交分享图
